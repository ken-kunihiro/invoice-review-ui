# 証憑レビューUI（invoice-review-ui）

領収書・請求書のPDF/画像をAIで読み取り、画面で確認・修正して、freee会計の「取引の一括登録」用CSVを出力するローカルツールです。データはすべてご自身のPC内に保存されます。

## できること

- PDF・画像（png/jpg）の証憑をドラッグ&ドロップまたはファイル選択で取り込み
- Claude（AI）による読み取り: 取引先・日付・金額・明細（税率別の行分割）・勘定科目・税区分
- 読み取り根拠のハイライト表示（書類のどこを読んだかを枠で表示）
- 事業所（会社）ごとの管理・削除
- freee会計「取引の一括登録」用CSV（Shift-JIS）の出力

## 必要な環境

- Windows 10 / 11
- Python 3.11以上
- Claude Code（推奨）または Anthropic APIキー

## セットアップ

Claude Codeに「このリポジトリをcloneしてREADMEどおりにセットアップして」と頼むのが一番簡単です。手動の場合は次のとおりです。

```
git clone https://github.com/fromk0326-boop/invoice-review-ui.git
cd invoice-review-ui
pip install -r requirements.txt
```

## AI読み取りの設定（どちらか一方でOK）

### 方法1: Claude Codeを使う（追加費用なし・推奨）

Claude Codeをインストール済みでログインしていれば、追加の設定は不要です。APIキーが見つからない場合、自動的にClaude Code経由で読み取ります。

### 方法2: Anthropic APIキーを使う（処理が速い）

[Anthropic Console](https://console.anthropic.com/) でAPIキーを発行し、このフォルダに `.env` ファイルを作成して次の1行を書きます。

```
ANTHROPIC_API_KEY=sk-ant-xxxxx
```

費用の目安は領収書1枚あたり1〜3円程度です。**APIキーは他人と共有しないでください。**

## 起動

`start.bat` をダブルクリックするか、ターミナルで次を実行します。

```
python server.py
```

ブラウザで http://localhost:3471 を開いてください。
（`index.html` をダブルクリックで直接開いても動きません。必ずサーバー経由で開いてください）

## アップデート

Claude Codeに「このツールをアップデートして」と頼むか、このフォルダで次を実行します。

```
git pull
```

変更内容は [CHANGELOG.md](CHANGELOG.md) をご覧ください。画面のバージョン表記と対応しています。

## 勘定科目ルールのカスタマイズ

勘定科目の判定基準は `rules.txt` に書かれています。ご自身の事務所のルール（「この取引先はこの科目」など）を書き足すと、次の読み取りからその基準で判定されます。

`rules.txt` はアップデート（git pull）で上書きされることがあります。事務所独自のルールは `rules.local.txt` という名前のファイルを同じフォルダに作って書くのがおすすめです（書き方は同じ。アップデートの影響を受けず、git にもコミットされません）。

## データの取り扱い

- 取り込んだ証憑・読み取り結果は、すべてこのフォルダ内の `_offices/` に保存されます（クラウドには保存されません）
- AI読み取りの実行時のみ、書類の画像がAnthropic（Claude）に送信されます。API経由の場合、送信データはモデルの学習には使用されません。Claude Code経由の場合はアカウントのプライバシー設定に従います
- 読み取り結果に住所・電話番号・口座番号は保存しない設計です（取引先名・インボイス登録番号のみ）
- 削除した証憑・事業所は `_offices/_trash/` に移動されます（完全削除はされないため、手動で戻せます）

## 注意事項

- 勘定科目・税区分の読み取り結果はAIによる推定です。**必ずご自身で確認のうえご利用ください。** 本ツールは税務判断を行うものではありません
- 顧問先の証憑を扱う場合は、ご自身の守秘義務・契約条件のもとでご利用ください
